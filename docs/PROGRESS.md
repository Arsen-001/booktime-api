  (`STORAGE_DRIVER=local` — папка, `s3` — любое S3-совместимое); выбор S3-хранилища — на этапе файлов.
- **Prisma 7.10.0, а не 8**: у `prisma` тег latest указывает на 8.0.0-rc (не выпуск).
