## Этап 1 — Сквозное (27.09.2026)

Сделано (`src/common/*`, `src/adapters/*`, модуль `CommonModule` — глобальный):
- `ids` — `<префикс>_<ULID>`, префиксы ядра как `ID_PREFIX` фронта + новые (`usr`, `ses`, `aud`, `fil`, `ntf`).
- `money` — bigint драмы, в JSON number; `percentOf` с округлением как в моке.
- `time` — только строгие форматы `'YYYY-MM-DD'` / `'YYYY-MM-DDTHH:mm'`, пояс филиала (по умолчанию Asia/Yerevan) ↔ UTC;
  «завтра в 4» и 30 февраля отбрасываются, а не превращаются в дату.
- `i18n` — тексты сервера ru/hy/en (тип требует ключ во всех трёх); ошибки — только кодами.
- `permissions` — копия списка фронта (39 прав) + шаблоны ролей; `npm run check:permissions` сверяет с фронтом.
- Контекст запроса (`req.ctx`: id запроса, IP, устройство, сессия из httpOnly cookie `bt_session`), guards
  `@Authed()` и `@Biz('право')` (арендатор из пути + права), `tenant(ctx)` для выборок. Сессии и членство —
  «розетки» `SESSION_RESOLVER` / `MEMBERSHIP_RESOLVER`: сейчас заглушки «всё закрыто», их заполнят этапы 2 и 3.
- Проверка входа `new Zod(schema)` → 400 `{ code: 'validation', fields }`.
- Версии: `ifMatch(req)` + `updateVersioned(...)` — атомарная правка по (id, version), чужая правка → 409 `conflict`.
- Журнал изменений: таблица `audit_events` (миграция `audit_events`), `AuditService.record(tx, ctx, …)` в той же
  транзакции, пишет только изменённые поля; `maskPhonesInDiff` для читателя без права на телефоны.
- `@Idempotent()` — Idempotency-Key, ответ хранится 24 ч в Redis, повтор отдаёт первый ответ (`Idempotent-Replay`),
  пока первый идёт — 409; ошибку можно повторить тем же ключом.
- «Отменить»: `UndoService.issue/undo`, `POST /v1/undo/{token}`, токен одноразовый, 10 с, только своей сессии.
- Живые изменения: `GET /v1/live?channels=…` (SSE) через Redis pub/sub, пульс 25 с; `me` → свой канал; бизнес-каналы
  закрыты до этапа 3 («розетка» `LIVE_ACCESS`).
- Лимиты: `@RateLimit({ bucket, limit, windowSec, by })` в Redis, 429 `rate_limited` + Retry-After.
- Адаптеры-заглушки (Р14): код входа (telegram/whatsapp/sms), пуш, почта, оплата, SMS бизнеса; хранилище — папка.

Проверено временным скриптом (не тест в репо — Р16): проверка входа отдаёт поля; повтор по ключу вернул первый ответ,
обработчик выполнился 1 раз, другой ключ — новый вызов; 4-й запрос → 429 с Retry-After; без сессии `@Biz`, `@Authed`
и `/v1/live` → 401; «Отменить» → 204, повтор → not_found; версия: верная → +1, устаревшая → 409; журнал записал
только изменённое поле; pub/sub доставил событие; 14:00 Ереван = 10:00 UTC. `tsc` 0, сверка прав — 39 совпадают.
